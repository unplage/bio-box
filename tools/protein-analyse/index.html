⚖️分子量与等电点（pI）

不同参数集结果可相差约 0.3–1.5 pH
成对扣除后仅未配对的奇余 Cys 带电
可靠性：结果仅为序列层面的理论估算。未考虑三维结构微环境、盐桥、金属离子及翻译后修饰， 与实验值典型偏差约 ±0.5–1.5 pH，不能替代等电聚焦等实验测定。
分子量：MW = Σ(残基平均质量) + 18.0153（水），残基质量取 ExPASy 平均同位素质量。
pI 算法：对每个可离子化基团按 Henderson–Hasselbalch 方程计算电荷，再二分法求净电荷 Q(pH) = 0 的 pH：
  Q(pH) = Σ正 1/(1+10pH−pKa) − Σ负 1/(1+10pKa−pH)
正电荷基团：N 端、His、Lys、Arg；负电荷基团：C 端、Asp、Glu、Cys、Tyr。Q(pH) 随 pH 单调递减，故解唯一。
pKa 参数集：可选 Bjellqvist/ExPASy、IPC_protein、EMBOSS、Sillero、Nozaki–Tanford。 Bjellqvist 额外按首/末残基修正末端 pKa（如 N 端 M→7.0、C 端 D→4.55）；IPC_protein 为 Kozlowski 2016 基于实验 pI 优化的九参数集。
Cys 状态：可全部按游离巯基、按二硫键成对扣除或完全氧化忽略；成键 Cys 的巯基不再电离。
结果解读：Bjellqvist 与 ExPASy ProtParam/Biopython 完全一致；IPC_protein 在蛋白实验数据集上通常更接近实测值； Sillero/Nozaki 等为经典参数集，蛋白基准误差通常更大。详见下方“不同 pKa 参数集结果对比”。

🔬A280 消光系数与浓度计算

分光光度计读数，无量纲
比色皿厚度，标准 1.0 cm
影响 ε 中 Cystine 贡献项
摩尔消光系数（Pace et al. 1995）： ε280 = 5500·n(W) + 1490·n(Y) + 125·n(Cystine)（M⁻¹·cm⁻¹）
Beer-Lambert 定律：A = ε · c · l ⟹ c(mol/L) = A / (ε · l)
质量浓度：c(mg/mL) = A · MW / (ε · l)（因 1 g/L ≡ 1 mg/mL）

🧪摩尔浓度 / 分子的量计算

或按下方模式换算
默认使用上方输入序列的计算值
用于浓度换算
与「质量」二选一优先使用本项
分子的量：n(mol) = m(g) / MW(g/mol)
摩尔浓度：c(mol/L) = n / V(L)；c(μM) = c(mol/L) × 10⁶
反向：m(g) = c(mol/L) × V(L) × MW

📐算法说明（力求主流、可复现）

目标函数（逐密码子最大化）：score = Σ ln w(cᵢ) − P_位点 − P_聚聚体 − P_GC窗口 − P_CpG
相对适应度（Sharp & Li 1987 CAI）：w(c) = f(c) / max f(同义密码子)，f 为物种每千密码子频率
CAI：exp( mean ln w )，不含终止密码子（值越接近 1 越贴近高表达基因偏好）
聚聚体：同一碱基连续 ≥5，每超出 1 个罚 4（自然对数单位）；GC 窗口：滑窗超出 [下限,上限] 罚 200×偏差²，偏离物种编码区 GC 罚 20×偏差²；CpG（可选）每个罚 2
搜索：beam search（宽度 60）逐密码子扩展同义候选并按累计得分剪枝；酶切位点为硬约束（当步禁止生成，含反向互补；位点按 IUPAC 正则匹配，N/R/Y 等简并碱基展开为字符类，如 SfiI 同时排除 GGCCNNNNNGGCC 及其全部中间可变变体）；结束后对残余位点/聚聚体/GC 违规做局部同义替换修复
数据：Kazusa Codon Usage Database（Nakamura et al. NAR 2003），GenBank R160 汇总

🧮引物熔解温度（Tm）计算

完全复刻 tools/Tm-calculate/primer_Tm-calculator.py：最近邻热力学模型 + 校准参数（56 条序列，RMSE 1.16°C），含 Na⁺ 盐校正、末端 AT 修正与退火温度建议；支持单序列、批量 FASTA 和每行一条纯序列。
对应 Python 版 Na⁺ 浓度，默认 50 mM
默认 0.25 μM；PCR 常用 0.1–0.5 μM
PCR 模式（默认）对称因子 4；退火模式对称因子 1
含 > 标题行时按 FASTA 解析；否则每行视为一条序列，自动过滤非 ATCG 字符。
算法说明（与 Python 版一致）：
  • 最近邻模型：SantaLucia 热力学参数，累加相邻碱基 ΔH/ΔS，再应用末端 AT 修正、熵缩放与起始修正。
  • 盐校正：ΔS′ = ΔS + 0.368 × (n−1) × ln([Na⁺]) × 1.6。
  • Tm：Tm = ΔH / (ΔS′ + R·ln(Ct/sym)) − 273.15；R = 1.987，PCR 模式 sym = 4，退火模式 sym = 1；分母 ≥ 0 时回退 Wallace 规则。
  • 退火建议：标准酶 Tm−3 ~ Tm−1°C；高保真酶 Tm+3 ~ Tm+5°C；梯度 PCR Tm−5 ~ Tm+5°C。
  • 适用：DNA 引物，长度 4–5000 bp，仅 ATCG。

Sharma 模型：η (cP) = 10[0.15 + 1.26·HI − 0.043·q − 0.020·qsym]
q：Fv 在 pH 5.5 的净电荷 = qVH + qVL，仅计 Asp/Glu/His/Lys/Arg（pKa 3.9/4.3/6.0/10.8/12.5，Berg 等）。
qsym：电荷不对称性 = qVH × qVL（FvCSP）。
HI：疏水指数 = −Σ疏水 Ei / Σ亲水 Ej，E 为 Eisenberg 归一化共识疏水标度； 疏水残基 A/C/F/I/L/P/V/W/Y，亲水残基 D/E/G/H/K/M/N/Q/R/S/T。
分层参考：<10 cP 低、10–20 cP 中、>20 cP 偏高。
局限：Sharma 模型在 180 mg/mL 条件下训练，对部分抗体偏差较大（如曲妥珠单抗实测约 8.6 cP，本模型约 16.6 cP）； 未考虑结构、盐浓度、辅料与聚集。DeepViscosity（Kalejaye/Lai 2025）使用 102 个 ANN 集成 + DeepSP CNN 特征， 需 ANARCI/IMGT 比对与外部模型权重，无法在离线单文件工具中复现，本面板不冒充其结果。

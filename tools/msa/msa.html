🧬 多序列比对工具 (MSA)

上传 FASTA 核酸或氨基酸序列（.fa / .fasta / .seq / .txt，可多文件合并）， 浏览器本地完成比对：两两 Needleman–Wunsch（仿射缺口）→ UPGMA 引导树 → 渐进 profile 比对。 计算在 Web Worker 中进行，数据不离开本机。

拖拽 FASTA 文件到此处，或 点击选择（可多选）
建议 ≤50 条 × ≤500 bp/aa
⚙️ 参数设置（全量）

📊 比对结果

· 缺口长度 k 代价 = gapOpen + (k−1) × gapExtend；默认两端缺口自由，可改为完全全局。
· 适用约 ≤50 条 × ≤500 bp/aa；更大规模请用 MUSCLE / MAFFT。精度接近 ClustalΩ，日常小规模分析足够。

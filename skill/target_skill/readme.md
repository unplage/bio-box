# 生物药靶点专利调研 Skill - 快速参考

## 一句话描述
系统性调研生物药靶点的全球专利布局、竞争格局和技术发展趋势，生成带引用证据的专业Word报告。

---

## 使用方法

### 方式1：自然语言触发
```
用户：帮我调研PD-1靶点的专利
用户：CD19靶点专利调研
用户：分析HER2的竞争格局
用户：VEGF专利分析报告
```

### 方式2：结构化指令
```
用户：进行EGFR靶点专利调研
- 时间范围：近5年
- 地域范围：全球
- 侧重点：竞争对手分析
```

## 报告结构（10个模块）

| 序号 | 模块 | 内容说明 |
|------|------|----------|
| 1 | 技术概述 | 靶点介绍、治疗机制、临床应用 |
| 2 | 专利检索策略 | 关键词、分类号、数据库 |
| 3 | 全球专利申请趋势 | 年度申请量、技术生命周期 |
| 4 | 专利区域分布 | 主要受理局、专利家族 |
| 5 | 主要申请人排名 | TOP20申请人、类型分布 |
| 6 | 重点竞争对手分析 | 3-5家核心竞争对手深度分析 |
| 7 | 技术路线分布 | CAR-T/双抗/ADC/单抗等 |
| 8 | 核心技术专利识别 | 高被引专利、基础性专利 |
| 9 | 结论与建议 | 竞争格局、技术趋势、风险提示 |
| 10 | 附录 | 参考文献（带引用链接） |

## 常用靶点速查

### 血液肿瘤
| 靶点 | 主要适应症 | 代表药物 |
|------|------------|----------|
| CD19 | B-ALL, DLBCL, FL | Kymriah, Yescarta, Breyanzi |
| BCMA | 多发性骨髓瘤 | Abecma, Carvykti |
| CD20 | B细胞淋巴瘤 | Rituximab |

### 实体瘤
| 靶点 | 主要适应症 | 代表药物 |
|------|------------|----------|
| PD-1 | 多种实体瘤 | Keytruda, Opdivo |
| PD-L1 | 多种实体瘤 | Tecentriq, Imfinzi |
| HER2 | 乳腺癌, 胃癌 | Herceptin, Kadcyla |
| EGFR | 非小细胞肺癌 | Iressa, Tarceva |
| VEGF | 多种实体瘤 | Avastin |

## 引用来源优先级

1. **一手资料**：Google Patents、USPTO、EPO
2. **官方数据**：FDA/NMPA批准信息、ClinicalTrials.gov
3. **权威分析**：Eureka LS、Patsnap、Beacon Intelligence
4. **企业公告**：上市公司年报、新闻稿
5. **学术文献**：PubMed、Web of Science

# 跨膜蛋白可溶性改造：STEAP1 设计方案与流程

> 目标：将全长人源 **STEAP1**（UniProt Q9UHE8，339 aa，六次跨膜铁/铜还原酶相关蛋白、肿瘤抗原）改造为可在水溶液中可溶表达的全长蛋白。
> 约束：**只改造跨膜区**；**胞外区（ECD）序列与构象完全不变**；哺乳动物细胞（Expi293/HEK293）表达；含 GPU 计算环境，可运行 AlphaFold2 / ProteinMPNN 全套流程。
>
> **（2026-08-13 定稿参数）** 模板：**先用 PDB 8UCD（3.0 Å，人 STEAP1 三聚体 + AMG 509 Fab）**，后续以 6Y9B 交叉验证；功能验证：**AMG 509 STEAP1 臂 Fab（BLI/SPR）**；设计目标：**C3 对称可溶三聚体**；血红素：仅固定 H175/H268 保留口袋、不纳入辅因子功能；FAD/酶活性：不处理。

---

## 一、文献方法学核心总结（以 Goverde 2024 Nature 为主）

下载到本目录 `solution-design/` 的文献见文末《文献清单》。方法学核心结论：

1. **简单地把疏水残基换成极性残基不够**——必须协同设计表面残基之间的相互作用（Goverde 2024 引文 18/40–42，另见小目录中 KcsA、水溶性 GPCR、QTY 三个先例各自的经验与局限）。
2. **QTY 代码（引文 21）**：仅把 TM 螺旋中的 LVIF 替换为 Q/T/Y。优点是极简、全程序列保持；缺点是改变量大、属于经验法，不保证骨架/构象，作者自己也提醒仅作起点。
3. **Goverde 2024 的 AF2seq-MPNN 流程**：
   - **AF2seq**：把 AF2 结构预测网络"反用"为骨架生成器（初始序列按二级结构编码 A=helix/V=sheet/G=loop，500 轮梯度下降，loss = FAPE + distogram + pLDDT + pTM），产出符合目标折叠的**新骨架 + 新序列**。
   - **MPNN / MPNNsol**：再用 ProteinMPNN 在这些骨架上设计序列。**关键**：普通 ProteinMPNN 会把膜蛋白拓扑的表面疏水残基"恢复"回来出现较差的可溶性；用**只含可溶蛋白训练集重新训练的 MPNNsol**（`github.com/dauparas/ProteinMPNN/tree/main/soluble_model_weights`）才能设计出表面疏水比例低的序列。
   - **功能保留策略（Figure 5，claudin 范例，与本任务最相关）**：设计时**显式固定功能基序的氨基酸与结构段，只在其上下文中把跨膜段可溶化**。claudin 用了两种成功策略：① 只重设计跨膜表面残基（约 40% 序列）；② 重设计整个跨膜区含核心（约 60% 序列）。固定残基表见其 Supplementary Table 2。实验上 ECD 抗原（CpE 毒素）结合活性与膜结合天然蛋白相当，并用 cryo-EM 验证复合物拓扑一致。
   - 不可溶/不折叠时的改进手段：**soft start**（从低置信轨迹重采样再跑）、**backrub/MD 骨架扰动作多样性**、**主链加高斯噪声的 MPNNsol**、AMBER 松弛后重预测。
4. **以原生结构为模板的"骨架固定"设计**（引文：Moffat 2021；ProteinMPNN 论文的固定区域解码）：当已有高分辨率实验结构且要求构象不变时，**不必**做 de novo 骨架生成，直接用原生骨架 + 固定残基 + MPNN(sol) 定点设计即可——这正是本任务采取的主路线。

## 二、STEAP1 结构 / 拓扑事实（设计输入）

| 项目 | 内容 | 来源 |
|---|---|---|
| 全长 | 339 aa，39.9 kDa，**同源三聚体** | UniProt Q9UHE8；JBC 2020 (6Y9B) |
| 跨膜螺旋 | h1:71–91, h2:119–139, h3:164–184, h4:218–238, h5:258–278, h6:291–311（UniProt 注释） | UniProt |
| 胞内结构 | N 端 1–~65（无折叠结构域，柔性）、C 端 312–339；细胞内环路 ICL1(140–163)、ICL2(239–257) | JBC 2020 |
| **胞外区 ECD** | **EC1(92–118，连 h1–h2)、EC2(185–217，含胞外螺旋 186–201 + loop，连 h3–h4)、EC3(279–290，连 h5–h6)**；无 UniProt 注释的糖基化/二硫键 | UniProt；JBC 2020 |
| 辅因子 | TMD 内 1 个血红素 B：保守 His **H175 / H268** 配位（跨膜区近胞外侧）；TMD 近胞内侧弱密度疑似 FAD | JBC 2020 |
| 抗体表位 | **AMG 509**（STEAP1×CD3 双特异 T 细胞衔接体 XmAb 2+1，亲合力依赖）STEAP1 臂 Fab；**mAb120.545**（不同抗体）；两者表位均落在 EC1+EC2，且**单 Fab 跨三聚体多亚基接触**（6Y9B 单 Fab 接触三个亚基，界面 ~5730 Å²/三聚体） | PDB 8UCD；JBC 2020；Cancer Discov 2024 |
| 可用结构 | **8UCD（主模板）**：人 STEAP1 三聚体 + 1×AMG 509 Fab，cryo-EM 3.0 Å；**6Y9B（交叉模板）**：三聚体 + 3×Fab120.545，2.97 Å | PDB |

**设计决策（已定稿）**
- 全长表达：保留 N 端 1–~65（胞内柔性段）、ICL1/ICL2、C 端 312–339（胞内尾）。
- ECD 序列与构象 100% 不变：EC1、EC2、EC3 全部残基**固定序列**，设计过程中**骨架坐标不对 ECD 开放自由度**。
- 表达系统：Expi293/HEK293（与 8UCD/6Y9B 的出发表达系统一致，天然糖基化保留）。
- 模板：**主模板 8UCD**（3.0 Å，解析残基与 STEAP1 天然序列无突变；注意其 STEAP1 构建体带 C 端 FLAG：`GGGGS-DYKDDDDK`，设计时剔除标签）；**交叉模板 6Y9B**（2.97 Å）。
- **关键判断（已确认：三聚体必须保留）**：AMG 509 的结合是**亲合力依赖（avidity-dependent）**——其 STEAP1 臂 Fab 与**三聚体上的复合表位**结合（8UCD 中三聚体仅承载 1 个 Fab；6Y9B 中单 Fab 跨三个亚基的 EC1+EC2）。因此**单体可溶形式将丢失 AMG 509 亲和力** → 设计目标锁定为 **C3 对称可溶三聚体**（对称性设计 + AF2-multimer 验证），而非论文中的单体可溶类似物。

## 三、总流程（Stage 0 – Stage 6）

```
Stage 0  结构与拓扑准备（模板、边界、功能位点清单）
Stage 1  区域划分与约束（固定/可设计掩码）
Stage 2  骨架准备（原生骨架 + 可选 MD/backrub 多样化）
Stage 3  序列设计（MPNNsol + 对称性 + 固定残基）
Stage 4  计算筛选（AF2 multimer 重预测 + 几何/序列过滤）
Stage 5  表达与验证（Expi293、SEC-MALS、CD、抗体结合）
Stage 6  迭代改进（不溶/无三聚/弱结合时的备选分支）
```

### Stage 0 — 结构与拓扑准备
1. 下载模板：PDB **8UCD**（主模板，AMG 509 Fab 结合态，3.0 Å）。交叉验证用 **6Y9B**（含 3×Fab120.545，表位信息更全；用户指定后续阶段切换复算）。
2. 建模型：取 8UCD 的 STEAP1 链（chain A/B/C，天然 C3 三聚体，剔除结构中的 STREP/FLAG 等标签序列）；**删除 Fab 链**（AMG 509 重/轻链）及共晶配体（HEM、FAD、XP4 等）坐标（配体坐标可另存，用于后续验证血红素口袋不被堵）。
3. 拓扑与边界定死（见上表）：TM h1–h6 按 UniProt 边界定界；ECD = EC1(92–118) + EC2(185–217) + EC3(279–290)；ICL/N/C 端按胞内段界定。可在 PDB 中再核对一遍实际残基号（cryo-EM 模型可能缺失残基）。
4. 补全缺失残基：cryo-EM 常缺残基（两端柔性段常未建模）；缺失处用 AF2（带模板 + MSA）补全为结构模板（**用 8UCD 真实序列预测**，勿用单序列模式，方法同 Goverde claudin 处理）。
5. 无序 N 端 1–65：保留全长序列；若其影响结晶/均一性，可在**后续实验验证**时评估，但**设计上不删除**（用户要求全长）。
6. 输出：`steap1_trimer_template.pdb`（基于 8UCD）+ `steap1_topology.tsv`（残基号→区段→固定/可设计标记）。

### Stage 1 — 区域划分与约束（掩码文件）
固定（**序列不设计、骨架不移动**）：
- ECD 全部残基：EC1(92–118)、EC2(185–217)、EC3(279–290)。
- 胞内功能/稳定残基：ICL1、ICL2、N 端(1–70)、C 端(312–339)（保证"全长原生"、"胞内区保留"）——这些区域本就亲水，无需设计。
- 血红素关键配位残基：**H175、H268**（及其直接邻位侧链接触 1–2 圈，避免可溶化设计把口袋堵住）。
- ECD–TM 交界深 1–2 个螺旋圈的 TM 端残基（建议保留，避免 ECD 构象被扰动）——若需要更多设计空间，此条可放宽为"固定序列但允许边角侧链翻转"，需重新评估 ECD RMSD。

可设计（默认策略①，论文最简且创伤最小）：
- **TM 脂质暴露残基**（h1–h6 的表层）。判定：OPM/PPM 膜取向 + SASA 选择器（Rosetta `LayerSelector` 或自算 SASA>40 Å²），标记为可设计位点，仅此部分开放（预计 ~40% 序列量，与论文"redesigning only the transmembrane surface"吻合）。
- 三聚体界面残基：**界面内侧残基保持原生**（维持三聚基底），**界面外侧（与脂接触侧）**可设计。
- 胞内侧 TM 表面残基（ICL 交界处 TM 面）同样开放设计。

备用策略②（Stage 6 失效时）：开放**整个 TM 区（含核心）**重设计（约 60% 序列，论文第二个成功策略），但**保留血红素口袋残基 + 三聚体界面核心**。

> 掩码输出：列出每个设计体系的 `*_fixed.csv`（残基号, 区段, 原因）。

### Stage 2 — 骨架准备
- **主路线（骨架零扰动）**：直接把 Stage 0 的三聚体模板当固定骨架。骨架坐标对 ECD 和可设计区都不放开 → 最稳，确保"胞外区构象不变"成立。
- **可选增强（建议做）**：给可设计 TM 段做有限骨架多样性（不与 ECD 冲突）：
  - MD 采样：GROMACS 在水/或用 POPC 双分子层短采样（参数用 Goverde 2024 补充方法），取快照作设计骨架；仅开放 TM 段灵活性，ECD 位置余弦约束或冻结。
  - 或 Rosetta backrub 只对可设计 TM 残基。
- 每条骨架都需跑后续 Stage 3–4，取高置信道。

### Stage 3 — 序列设计（ProteinMPNN / MPNNsol）
1. 工具：`github.com/dauparas/ProteinMPNN`（含 MPNNsol 权重 `soluble_model_weights`）。
2. 输入：三聚体骨架（3 链，链内顺序 1–339 interleave？按链 A/B/C 顺序），**对称性耦合**：三聚体等价位点用 ties 文件（等同位序列一致）。
3. 固定位点：按 Stage 1 掩码写入 `*_fixed.csv`（对应 ProteinMPNN `--fixed_positions_json_file`）。
4. 采样：每个骨架建议 ≥100 设计，不同高斯噪声种子（0.1 Å / 0.2 Å 两套权重）+ 若干 seed；无噪输入骨架；**屏蔽 Cys**（`--omit_AA C`，原生无功能的 Cys 一律不引入）。
5. 若一步可溶序列回收不佳：改用"偏置采样"（对极性氨基酸正偏置、Ala 负偏置）或"整 TM 区重设计"分支。
6. 输出：`.fa`（设计序列）+ 设计的 `_design.pdb`（把序列回写到骨架上）。

### Stage 4 — 计算筛选（统一标准）
1. **AF2 / AF2-multimer 重预测**：对每跳设计跑 3 recycles + AMBER/IPA 松弛；三聚体用 multimer 权重预测并检查对称一致性。
2. 几何过滤（参考论文阈值）：
   - 全蛋白 TM-score（相对 6Y9B 模板）**≥ 0.80**；
   - **ECD 段 RMSD（Cα，仅 EC1+EC2+EC3）< 1.0 Å** → 这是"胞外区构象不变"的直接判据；
   - pLDDT ≥ 80（ECD 上尤其高）；
   - 三聚体 ipTM ≥ 0.8（若走多聚体重预测）。
3. 可溶过滤：
   - **表面疏水占比**（Rosetta：SASA>40 Å² 的残基中 `GPAVILMFYW` 占比）**≤ ~0.30**（与 Goverde MPNNsol 设计一致），且相对原生膜表面（远大于此）显著降低。
   - 无暴露芳香/极端疏水斑块：可设计表面平均疏水性/亲水界面检查（可选 MD 快照统计）。
4. 序列过滤：e-value（BLAST 对 RefSeq）> 0.1 保证设计新颖；无冗余无害 Cys。
5. 结构合理性：血红素口袋（H175/H268 侧链取向、口袋体积）在三聚体内保持；三聚体界面接触残基基本原生。
6. 输出 top ~10–30 设计 → Stage 5。

### Stage 5 — 表达与验证（Expi293 / HEK293）
1. 表达构建：密码子优化，C 端 His6/Strep 标签（可加 TEV 位点），Expi293 瞬转。**参考 6Y9B 的已证实路线**：HEK293（GnTI− 亦可）、Strep 标签、digitonin/GN 抽提——但我们的目标是无去污剂可溶，故希望蛋白**分泌到上清**或**在去污剂抽提后透析/置换到水相**。
   - 由于保留全长 TMD 且 TM 段已可溶化，天然信号肽（若有）→ 分泌路径可形成二硫键/糖基（本蛋白该方面注释为无，但以结构为准复核）；若 TM 仍锚定，先轻度去污剂（如 DDM/CHS）抽提纯化后，置换至无去污剂缓冲液验证可溶。
2. 可溶性/三聚体判据：
   - **SEC-MALS**：单体 ~39.9 kDa；**天然三聚体 ~120 kDa**；预期主峰为 ~120 kDa（多聚状态标峰）。
   - **CD/热稳定性**：α-螺旋占比高；Tm ≥ 60 °C（可作为筛选阈值，参考论文可溶 CLF/GLF 多 >90 °C）。
3. **功能判据（核心）——AMG 509 结合**：用 **AMG 509 的 STEAP1 结合臂 Fab**（8UCD 结构中的 Fab，中检可与结构表位逐残基对照）做 **BLI（Octet）或 SPR**，测 Kd。AMG 509 奏效严格依赖三聚体上的复合表位（avidity），因此"强结合 + 与 8UCD 表位吻合"即可同时验证 ECD 构象与三聚装配（该方法与论文 claudin–CpE 用 BLI 验证一致）。
   - 交叉验证：再用 mAb120.545 Fab（6Y9B 结构同源性抗体）复测；备选 anti-STEAP1 商业抗体 ELISA + 与天然 HEK/MDA-PCa2b 细胞的竞争结合。
4. 骨架验证（可选高级）：复合物 cryo-EM 复现 8UCD 的结合位姿，或 HDX——高度可选，非必需。

### Stage 6 — 迭代分支（分别对应常见失败模式）
| 现象 | 对策 |
|---|---|
| 大量不溶/聚沉 | 跳到策略②整 TM 区重设计；换 MPNNsol 另一噪声权重；对 TM 段做 MD 骨架多样化后重设计；检查是否血红素口袋掏空导致核心塌陷（保留口袋残基更多）；降低固定范围（放宽 ECD–TM 交界 1–2 圈）后重跑，重验 ECD RMSD |
| 可溶但单体为主（无三聚） | 增加三聚体界面宿量：允许界面 TM 侧边缘残基重设计以补偿溶液中聚合倾向；AF2-multimer 过滤阈值提高；或接受单体 + 改功能验证方式（此时需接受抗体亲和力可能下降的风险，需向用户确认接受度） |
| 可溶三聚但抗体结合丢失 | 检查 ECD–TM 交界刚接是否被扰动；对 EC2 loop 与 TM 交界残基增加固定圈数；用结合确实的点突变为验证（方法同 JBC 2020 的 R32E/N99D 对照，8UCD 的 Fab 表位逐残基移位验证）；回过头比较 8UCD 表位 zone 与设计模型 |
| 表达量低 | 优化信号肽/标签位置；瞬转条件（提高质粒量、18 °C、Media 体积）；融合促表达标签（如 Fc/GST 需后续切除） |

## 四、依赖的工具与关键参数
- **AlphaFold2 / AlphaFold-multimer**：预测与重验证（模板预测阶段用 MSA+templates；筛选阶段用 multimer、3 recycles、AMBER 松弛）。
- **ProteinMPNN（含 MPNNsol 权重）**：定点序列设计；对称 ties；固定残基掩码。
- **Rosetta（3）**：SASA/层选择器算表面疏水占比；FastRelax；backrub 骨架多样化（可选）。
- **OPM / PPM 2.0**：膜取向 → 定义脂质暴露 TM 表面残基。
- **GROMACS**（可选）：MD 骨架采样 + 最终水环境稳定性抽查。
- **TM-score（TM-align）、Foldseek、Biopython**：几何比对与 RMSD 统计。
- 参数建议参照论文：w(FAPE)=1.0，w(pLDDT)=0.2，w(pTM)=0.2，distogram 0.5（trajectory 中后期可关）；过滤阈值 TM>0.80、pLDDT>80、e-value>0.1。

## 五、风险与注意事项（务必先读）
1. **三聚体是功能前提**：mAb120.545 表位跨亚基。若不能形成稳定可溶三聚体，抗体功能验证将失败 → 建议主路线即用对称 C3 设计，不要一开始就做单体。
2. **血红素口袋**：不保留口袋（或核心全重设计）在无膜环境中可能形成空腔/不稳定。至少固定 H175/H268 与邻位，设计保留口袋体积；如后续要做还原酶功能，则整袋/辅因子需另行处理（本项目以可溶+抗体结合为主要目标，可暂不考虑辅因子功能）。
3. **"全长+胞内域保留"的影响**：CIE 1–65 无序、C 端与 ICL 亲水，通常有益于可溶；但若出现聚集，可回溯评估这些区域对构象均一性的影响（用户已确认需保留，因此只作观测不作修改）。
4. **关键交界**：ECD–TM 交界是全方案最脆弱处。默认固定交界 1–2 圈；任何放宽都必须重新跑 ECD RMSD 判据。
5. **确认天然形态**：正式开工前，确认是否以 6Y9B 构象（结合 Fab 的构象）为设计模板；若后续应用需要 apo/不同构象，模板需另行准备。
